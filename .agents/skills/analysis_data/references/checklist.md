# チェックリスト: data.ipynb

データ収集・前処理の5ステップのうち、ステップ1〜3を行う。
ステップ4の前処理と、ステップ5の加工は analysis.ipynb で行う。

## 安全性
- 個人情報を抽出していない。必要な場合はマスキングしている

## ステップ1: データ品質の確認
- データの出所を確認し、信頼できるデータか判断している

## ステップ2: 複数データの結合
- 複数データを結合する場合、JOIN で意図せずレコードが増えていない

## ステップ3: 探索的データ分析
- レコード数を確認している
- 各列のデータの種類と意味合いを、ビジネス上の意味まで言語化している
- 各列の桁数と単位を確認している
- 欠損値と外れ値の有無を確認している
- サンプルサイズがサブイシューの比較に十分か評価している

## 申し送り
- 注意点と限界を、アラートとして書いている
- ステップ4、5で必要な前処理と加工を書いている
- 外れ値は除外せず、ビジネスのヒントやヒアリング対象の候補として書いている
- analysis.md の 1-2② の想定と、実データのずれを記載している
