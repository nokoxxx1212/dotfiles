# チェックリスト: data.ipynb

高度な前処理は行わない。構造理解と安全確認に徹する。
BigQuery のスキャン量チェックは、本スキルの対象外。hook で対応する。

## 抽出条件と安全性
- 個人情報を無防備に抽出していない
- 不要な個人情報はカラムごと削除している
- 必要な個人情報はハッシュ化などでマスキングしている
- JOIN で意図せずレコードが増えていない
- JOIN キーの一意性を確認している

## 構造理解とビジネスルール
- 対象テーブルのキーとリレーションを把握している
- カラムの値の分布から、フラグ等のビジネス上の意味を推測し、言語化している

## 基礎プロファイリング
- 欠損値の割合を算出し、分析への影響を評価している
- ビジネスロジック上あり得ない値を検知している
- 外れ値を検知している
- 主要変数の分布とカーディナリティを確認している
- サンプルサイズがサブイシューの比較に十分か評価している

## 申し送り
- データ利用上の注意点、限界、リスクを、アラートとして書いている
- analysis.md の 1-2② の想定と、実データのずれを記載している
