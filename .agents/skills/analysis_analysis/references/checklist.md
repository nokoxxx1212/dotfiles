# チェックリスト: analysis.ipynb

## 前処理
- data.ipynb の申し送りを確認している
- 申し送りのリスクに対応した前処理を実行している
- JOIN、フォーマット変換、特徴量作成を実行している

## 比較視点
- 論点ごとに、比較視点を明確にしている
- A/B比較（介入群と統制群など）
- 時系列比較（施策前後、前年同期比など）
- セグメント比較（新規と既存など）

## 統計的妥当性
- 比較する各群のサンプルサイズを確認している
- 相関を因果と取り違えていない
- 交絡因子を考慮している
- 有意差だけでなく、効果量（ビジネスインパクト）を評価している

## 洞察
- 観察事実で終わらず、「なぜそうなったか」まで掘り下げている
- 論点ごとに、空（事実）・雨（解釈）・傘（アクション）が揃っている
- 仮説に対する当たり外れを示している

## 可視化
- 要素の多い円グラフ、不要な3Dグラフ、二重軸の乱用を使っていない
- メッセージに不要なグリッド線や背景色がない
- グラフのタイトルが、結論を表している

## アクション
- 「明日から何をすべきか」まで書いている
- 理論解をそのまま提案せず、現場の運用上の制約を考慮している
