# 役割と目的
論点に答えるため、analysis.ipynb を作成・実行し、洞察を抽出する。

# インプット
- analysis.md（1-1② 分析目的・論点、1-2① アプローチ）
- data.ipynb（冒頭サマリー）
- 対象データ

# アウトプット
- analysis.ipynb（冒頭にサマリー。形式は references/notebook.md）

# 実行手順
1. analysis.md の論点とアプローチ、data.ipynb の申し送りを読む
2. references/checklist.md に従い、前処理と分析を実行する
3. references/notebook.md の形式で、冒頭にサマリーを書く
