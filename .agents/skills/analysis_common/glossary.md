# 用語集

全スキルで以下の用語に統一する。

## 用語
- **イシュー**: 分析全体で答える問い。1つだけ立てる。比較を意識して設定する。
- **切り口**: イシューを分解する観点。仮説思考で設定する。
- **サブイシュー**: 切り口ごとに分解した問い。「〜か？」の形式で書き、番号を振る。
- **イシューツリー**: イシュー → 切り口 → サブイシューの3階層。
- **仮説**: サブイシューに対する仮置きの答え。
- **クロス軸**: クロス集計で比較に使う軸。属性、行動、意識の観点で洗い出す。
- **縦の論理・横の論理**: 「なぜそうなるの？」「それだけ？」に答えられること。
- **意思決定**: 誰が何を決めるか。分析実施の背景に書く。
- **空・雨・傘**: 事実、解釈、アクション。
- **申し送り**: data.ipynb から後段へ渡す、データ利用上の注意点と限界とリスク。

## 使わない言葉
- 課題、論点 → イシュー、サブイシュー
- 提案書、報告書 → analysis.md

## 成果物
- `analysis.md`: 1 分析概要 / 2 分析結果 / 3 グラフ集 / 4 Appendix
- `data.ipynb`: 冒頭にサマリー
- `analysis.ipynb`: 冒頭にサマリー

## サブイシュー番号
- 1-1② で振った番号を、2-2 でも同じ番号で使う。

## 担当範囲
- 各スキルは担当章だけをレビュー・実行する。他章は参照のみ。
