# 用語集

全スキルで以下の用語とルールに統一する。

## 用語
- **イシュー**: 分析全体で答える問い。1つだけ立てる。比較を意識して設定する。
- **切り口**: イシューを分解する観点。仮説思考で設定する。
- **サブイシュー**: 切り口ごとに分解した問い。「〜か？」の形式で書き、番号を振る。
- **イシューツリー**: イシュー → 切り口 → サブイシューの3階層。
- **仮説**: サブイシューに対する仮置きの答え。
- **クロス軸**: クロス集計で比較に使う軸。属性、行動、意識の観点で洗い出す。
- **意思決定**: 誰が何を決めるか。分析実施の背景に書く。
- **空・雨・傘**: 確かめた事実、解釈、アクション。
- **申し送り**: data.ipynb から後段へ渡す、データ利用上の注意点と限界。

## 使わない言葉
- 課題、論点 → イシュー、サブイシュー
- 提案書、報告書 → analysis.md

## 成果物
- `analysis.md`: エグゼクティブサマリー / 1 分析概要 / 2 分析結果 / 3 Appendix
- `data.ipynb`: 冒頭にサマリー
- `analysis.ipynb`: 冒頭にサマリー

## 書き方
- 確かめた事実と推測を分けて書く。推測には「推測」と明記する
- 図表で語り、文章は最小限にする
- 同じ数字を繰り返し書かない
- エグゼクティブサマリーは、結論の表1つにする
- 図表の下の説明は1行にする

## 更新方針
- 分析中にイシューやサブイシューが変わったら、番号を振り直す
- 継ぎ足さず、初見の人が上から順に読んで理解できる構成に作り直す
- 変更の履歴は git に残し、analysis.md には残さない

## サブイシュー番号
- 1-1② で振った番号を、2-1 でも同じ番号で使う。

## 担当範囲
- 各スキルは担当章だけをレビュー・実行する。他章は参照のみ。
