# 用語集（analysis系スキル共通）

全スキルで以下の用語に統一する。

## 用語
- **論点**: 分析で答える問い。必ず「〜か？」の形式で書く。
- **メイン論点**: 最上位の論点。
- **仮説**: 論点に対する仮置きの答え。
- **意思決定**: 誰が何を決めるか。分析目的に含める。
- **空・雨・傘**: 事実（空）、解釈・洞察（雨）、アクション（傘）。
- **申し送り**: data.ipynb から後段へ渡す、データ利用上の注意点・限界・リスク。

## 使わない言葉
- 課題、イシュー、サブイシュー → 論点
- 提案書、報告書 → analysis.md
- Step 3 / Step 4 のノートブック名 → data.ipynb / analysis.ipynb

## 成果物
- `analysis.md`: 1-1 与件整理 / 1-2 実施概要 / 2 分析結果 / 3 グラフ集 / 4 Appendix
- `data.ipynb`: 冒頭にサマリー（申し送り）
- `analysis.ipynb`: 冒頭にサマリー（論点ごとの空・雨・傘）

## 論点番号
- 1-1② で振った論点番号を、2-2 の論点別サマリーで同じ番号で使う。

## 担当範囲
- 各スキルは担当章だけをレビュー・実行する。他章は参照のみ。
