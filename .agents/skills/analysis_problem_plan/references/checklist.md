# チェックリスト: 1-1 与件整理 / 1-2 実施概要

## 全般
- 担当は 1-1・1-2 のみ。他章は参照のみ
- 各章に【タイトル】【キーメッセージ（1〜2行）】【本文（箇条書き）】がある
- 5W1H が明確で、章構成が MECE
- 情報過多の章は2階層に分割されている
- 用語が glossary.md に沿っている

## 1-1① 分析実施の背景
- 現状が事実として書かれている
- ゴール（ありたい姿）が書かれている
- 現状とゴールのギャップが読み取れる
- 分析する意義が示されている

## 1-1② 分析目的・論点
- 目的に「誰が」「何を決めるか」が含まれている
- 目的が「〜の分析」ではなく「〜の明確化」「〜の検証」など白黒つく表現
- メイン論点がある
- 論点が「〜か？」の形式
- 論点が MECE で、番号が振られている
- 各論点に仮説がある
- 各論点に「仮説が正しければ〜する」というアクションがある

## 1-1③ スコープ
- 対象範囲が明確
- 対象外（今回答えない問い）が明確
- 早期に小さな成果を出せる範囲に絞られている

## 1-2① アプローチ
- 手法が説明されている
- 手法の選択理由が書かれている
- 比較設計（A/B、時系列、セグメント）が論点に対応している

## 1-2② 対象データ
- データソースが明記されている
- 対象者・期間・除外条件が明記されている
- 抽出・紐付けが可能という根拠がある
- サンプルサイズが十分と見込める
- バイアスのリスクと対処方針がある
- 個人情報の扱いが考慮されている

## 1-2③ 実行計画
- スケジュールとマイルストーンがある
- 途中でアウトプットを見直すフェーズがある
- 責任者・意思決定者・担当者が明記されている
- 費用・リソースがある

## 1-2④ リスク
- データ不足・想定外の結果が出た場合のリスクと代替案がある
- 倫理・法務リスク（個人情報、バイアス）が考慮されている

## Appendix との整合
- 1章で使う用語・指標の定義が、Appendix にある
- 指標は分母・分子・集計期間・除外条件まで定義されている
