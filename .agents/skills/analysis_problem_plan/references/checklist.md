# チェックリスト: 1-1 与件整理 / 1-2 実施概要

## 全般
- 各章に【タイトル】【キーメッセージ】【本文】がある
- 章構成が MECE
- 縦の論理と横の論理で、突っ込まれない構成と文章になっている

## 1-1① 分析実施の背景
- 現状とゴールのギャップが読み取れる
- 誰が何を決めるかが書かれている
- 分析する意義が示されている

## 1-1② イシュー
- イシューが1つだけ、「〜か？」で白黒つく表現で書かれている
- イシューが比較を意識して設定されている
- イシュー → 切り口 → サブイシューのツリーで分解されている
- 切り口が仮説思考で設定され、MECE
- サブイシューが「〜か？」の形式で、番号が振られている
- 各サブイシューに、仮説と、仮説が正しい場合のアクションがある

## 1-1③ スコープ
- 対象外が明確
- 早期に小さな成果を出せる範囲に絞られている

## 1-2① アプローチ
- 手法の選択理由が書かれている
- 全体集計で俯瞰し、クロス集計で詳細を見る流れになっている
- クロス軸が属性、行動、意識の観点で洗い出され、切り口に対応している

## 1-2② 対象データ
- データの出所と信頼性が確認されている
- 抽出と紐付けが可能という根拠がある
- サンプルサイズが十分と見込める
- バイアスのリスクと対処方針がある
- 個人情報の扱いが考慮されている

## 1-2③ 実行計画
- 途中でアウトプットを見直すフェーズがある
- 意思決定者が明記されている

## 1-2④ リスク
- 想定外の結果が出た場合の代替案がある
- 倫理・法務リスクが考慮されている

## Appendix との整合
- 1章で使う用語と指標が、Appendix で定義されている
- 指標は分母、分子、集計期間、除外条件まで定義されている
